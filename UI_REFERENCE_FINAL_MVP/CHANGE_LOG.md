# Change Log — Final MVP UI Reference Pack

**Append-only.** Add every new entry at the **bottom**. Never edit, reorder or delete an existing entry — a superseded entry is corrected by a later entry that says so explicitly. Historical records are never rewritten to conceal a prior decision.

Log a change whenever:

- a `reference.png` is added, replaced or re-frozen;
- a Figma node changes for a screen;
- a canonical or implemented route changes for a screen;
- the live Figma canvas has moved on and a deliberate re-freeze is performed;
- a screen's screenshot priority, flow order or scope membership changes.

**All timestamps are Asia/Singapore.**

---

## Rules

- **A change to a frozen reference requires operator approval.** The frozen screenshot is the visual authority for its implementation checkpoint; replacing it silently would let an implementation drift toward an unreviewed frame.
- **A node or route change is recorded here and reconciled against the ratified inventory.** This log does not amend the inventory, Amendment 005 or Amendment 006 — where they disagree, the ratified instrument governs and the disagreement is reported.
- **Record the affected implementation checkpoint**, so a completed visual acceptance that is now stale is visible rather than assumed valid.
- **Never backdate an entry.**
