# Trainer - Lesson Plan

## Screen purpose

- Allows a trainer to review the weekly lesson plan and teaching materials for a selected class and term.

## Page sections and UI components

- Trainer Portal sidebar.
- **Lesson Plan** heading.
- **Back to My Classes** control.
- Class summary banner.
- Term selector.
- Status legend for Completed, This week, and Upcoming.
- Weekly lesson cards with dates and locations.
- Focus-point tags.
- Slides and materials list.
- Signed-in trainer profile.

## What each section displays

- The Class banner displays the Programme, Level, Term, schedule, room, and Student count.
- Each lesson card displays the lesson topic, date, location, focus points, status, and available materials.
- Upcoming lessons without resources display “Slides not uploaded yet.”

## User interactions

- Change the selected term.
- Review completed, current, and upcoming lessons.
- Select an available slide deck or material.
- Return to My Classes.

## Button and navigation behavior

- **Back to My Classes** opens `Trainer -  My Classes`.
- The term selector changes the displayed lesson plan.
- Selecting a listed material opens or downloads it.
- Sidebar items open their corresponding trainer pages.
- **Logout** returns to the trainer login screen.
