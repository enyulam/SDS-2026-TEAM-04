# Trainer - Schedule

## Screen purpose

- Allows a Trainer to view their Classes, Lessons, and meetings on a monthly calendar.
- Provides details and a start action for the selected Lesson.

## Page sections and UI components

- Trainer Portal sidebar.
- **Schedule** heading and description.
- Month selector.
- Schedule search field.
- Monthly calendar with class entries.
- Selected-day details panel.
- Lesson card with date, time, room, assigned Trainer, and Trainer Assistant (TA).
- **Start Class** button.
- Signed-in trainer profile.

## What each section displays

- The calendar displays the Trainer’s scheduled Lessons and meeting times.
- The details panel identifies the selected day, Class, and Lesson.
- The Lesson card displays the Class location, assigned Trainer, and Trainer Assistant (TA).

## User interactions

- Change the displayed month.
- Search the schedule.
- Select a date or calendar event.
- Start the selected class.
- Use the sidebar to open another trainer section.

## Button and navigation behavior

- The month selector changes the displayed calendar period.
- The search field narrows the visible schedule items.
- Selecting a calendar entry updates the details panel.
- **Start Class** opens `Trainer - Student Roster` for the selected Lesson.
- **Logout** returns to the trainer login screen.
