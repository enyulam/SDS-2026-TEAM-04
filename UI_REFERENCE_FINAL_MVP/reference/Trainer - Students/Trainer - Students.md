# Trainer - Students

## Screen purpose

- Allows a Trainer to browse Students across their assigned Classes and review recent B.E.S.T. Rating information.

## Page sections and UI components

- Trainer Portal sidebar.
- **Students** heading and description.
- **My Students** count.
- Class filter.
- Student search field.
- Student table.
- Columns for Student, Class, Last assessed, and B.E.S.T. Rating.
- Signed-in trainer profile.

## What each section displays

- The summary displays the number of Students in the Trainer’s assigned Classes.
- Each row displays a Student’s name, Class, most recent assessment date, and current B.E.S.T. Rating.
- A dash is shown when no recent assessment date is available.

## User interactions

- Filter students by class.
- Search for a student.
- Select a student row.
- Use the sidebar to open Dashboard, My Classes, Reports, or Schedule.

## Button and navigation behavior

- The class filter changes the visible student rows.
- The search field narrows the list by student.
- Selecting a student row opens the student’s relevant profile or report information.
- Sidebar items open their corresponding trainer pages.
- **Logout** returns to the trainer login screen.
