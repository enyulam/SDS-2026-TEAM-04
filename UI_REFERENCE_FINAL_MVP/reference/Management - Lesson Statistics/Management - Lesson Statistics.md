# Management - Lesson Statistics

## Screen purpose

- Shows assessment results and delivery information for one class lesson.

## Page sections and UI components

- Management Portal sidebar.
- Class and lesson breadcrumb.
- **Lesson Statistics** heading and lesson summary line.
- Summary cards for Students, assessed count, and B.E.S.T. Rating distribution.
- **Skill Averages** chart.
- **Status Distribution** section.
- **Trainer & Trainer Assistant (TA) — This Lesson** section.
- **Student Breakdown** table.
- **Class Overview** return link.
- Signed-in Management profile.

## What each section displays

- The lesson summary identifies the lesson number, topic, date, time, and room.
- Skill Averages displays class percentages for each rubric criterion.
- Status Distribution displays counts for Beginning, Developing, Mastering, and Mastered.
- Trainer and Trainer Assistant (TA) displays staff details, delivery tasks, and completion indicators for the Lesson.
- Student Breakdown lists each assessed Student’s strongest area, focus area, and B.E.S.T. Rating.

## User interactions

- Review lesson-level performance and staff delivery information.
- Compare individual student outcomes.
- Select a Student row when more detail is needed.
- Return to the class overview.

## Button and navigation behavior

- **Class Overview** opens `Management - Class Overview`.
- A selectable Student row opens the related Student profile or report.
- Sidebar items open their corresponding management pages.
- **Logout** returns to the management login screen.
