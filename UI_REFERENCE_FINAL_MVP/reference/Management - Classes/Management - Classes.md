# Management - Classes

## Screen purpose

- Allows Management to browse all academy Classes by Level.
- Summarises each Class’s Programme, assigned Trainer, Trainer Assistant (TA), Student count, and report progress.

## Page sections and UI components

- Management Portal sidebar.
- **Classes** heading.
- Level tabs for All Classes, Junior, Intermediate, and Advanced.
- Class cards for Public Speaking and Speech and Drama.
- Assigned Trainer and Trainer Assistant (TA) names on each card.
- Student-count and report-progress indicators.
- Signed-in Management profile.

## What each section displays

- The level tabs display the available class categories and their class totals.
- Each Class card displays the Programme abbreviation, Level, Class title, assigned Trainer, Trainer Assistant (TA), number of Students, and report completion count.

## User interactions

- Filter the class list by level.
- Select a class card to view its class overview.
- Use the sidebar to open other management sections.

## Button and navigation behavior

- **All Classes** shows classes across every level.
- **Junior**, **Intermediate**, and **Advanced** filter the cards to the selected level.
- Selecting a class card opens `Management - Class Overview` for that class.
- **Logout** returns to the management login screen.
