# Management - Create Parents Account

## Screen purpose

- Allows Management to create a Parent Portal account for a selected Student.

## Page sections and UI components

- Management Portal sidebar.
- **Create Parent Account** heading and student breadcrumb.
- **Parent Details** section.
- Full name, relationship, email address, and phone fields.
- Selected-student card showing Alicia Gomez, class, and student ID.
- **Portal Access** section.
- **Send email invite** toggle.
- **Cancel** and **Create Account** buttons.
- Signed-in Management profile.

## What each section displays

- Parent Details displays the Parent’s identity, relationship to the Student, and contact information.
- The Student card identifies the Student whose approved reports the Parent can view.
- Portal Access explains that an email invite gives the parent a link to set a password and sign in.

## User interactions

- Enter or edit the Parent’s details.
- Select the Parent’s relationship to the Student.
- Turn the email invitation option on or off.
- Cancel or create the account.

## Button and navigation behavior

- **Cancel** returns to the student area without creating an account.
- **Create Account** submits the Parent-account form for the displayed Student.
- The email-invite toggle controls whether an invitation is sent as part of account creation.
- **Logout** returns to the management login screen.
