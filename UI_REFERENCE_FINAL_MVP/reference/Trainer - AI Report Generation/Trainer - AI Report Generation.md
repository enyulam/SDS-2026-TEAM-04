# Trainer - AI Report Generation

## Screen purpose

- Allows a Trainer to review, edit, and submit an AI-generated Student Report for one Lesson.
- Supports adding remarks and class video evidence before submission.

## Page sections and UI components

- Trainer Portal sidebar.
- **AI Report Generation** heading and review status label.
- **Back to Student Roster** control.
- Student list with report statuses.
- Editable report sections for Overview, Strengths, and Areas to Grow.
- **Remarks** input.
- **Class Video Evidence** upload area.
- **Report Details** card.
- **Performance Summary** tiles.
- **Confirm & Submit** and **Save as draft** actions.
- Signed-in trainer profile.

## What each section displays

- The student list shows Students and report statuses such as Approved.
- The main report displays a draft narrative for Alicia Gomez.
- Report Details identifies the Student, Class, Lesson, and Term.
- Performance Summary displays the Student’s B.E.S.T. Ratings for key speaking criteria.
- The upload area accepts the Student Video recorded during the Lesson.

## User interactions

- Select a student from the list.
- Review and edit the generated report text.
- Add optional remarks.
- Drag and drop or select class recordings for upload.
- Save the report as a draft or confirm submission.
- Return to the student roster.

## Button and navigation behavior

- **Back to Student Roster** opens `Trainer - Student Roster`.
- Selecting a student loads that student’s report draft.
- The upload area opens a file selector when clicked.
- **Save as draft** preserves the current report without submitting it.
- **Confirm & Submit** sends the displayed Student Report to Management for approval.
- **Logout** returns to the trainer login screen.
