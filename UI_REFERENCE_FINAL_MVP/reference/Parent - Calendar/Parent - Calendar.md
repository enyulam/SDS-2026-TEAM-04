# Parent - Calendar

## Screen purpose

- Gives a Parent a calendar view of the selected Student’s Lesson progress and approved reports.
- Explains the B.E.S.T. Rating colours used throughout the portal.

## Page sections and UI components

- Parent Portal sidebar with Overview, Calendar, Reports, and Logout.
- **Alicia’s Progress Calendar** heading.
- Month calendar with colour-coded dates.
- Selected-Lesson progress card with B.E.S.T. Rating, observation, and skill tags.
- **View Report** action.
- Monthly encouragement summary.
- **What the colours mean** legend.
- **Recent Reports** list.
- Student selector and signed-in Parent profile.

## What each section displays

- The calendar displays daily progress using Beginning, Developing, Mastering, and Mastered colours.
- The selected-day card displays a trainer observation and the assessed skills for that date.
- The monthly summary displays the number of mastered days and a short progress message.
- Recent Reports displays recent lesson topics, programmes, trainers, and dates.

## User interactions

- Select a calendar date.
- Move to the previous or next month.
- Open the selected day’s report.
- Select a recent report.
- Change the Student being viewed using the Student selector.

## Button and navigation behavior

- Calendar arrows move between months.
- Selecting a date updates the daily progress card.
- **View Report** opens the report for the selected day.
- Selecting a recent report opens its detailed report.
- **Overview** opens `Parent - Dashboard`; **Reports** opens the parent report list.
- **Logout** returns to the parent login screen.
