# Management - Add Trainer

## Screen purpose

- Allows Management to create a Trainer or Trainer Assistant (TA) profile and optionally assign Classes.

## Page sections and UI components

- Management Portal sidebar.
- **Add Trainer** heading and `Trainers / Add` breadcrumb.
- **Trainer Profile** section.
- Photo upload area.
- First name, last name, email, phone, employee ID, and role fields.
- **Assign Classes** section with selectable class chips.
- **Cancel** and **Add Trainer** buttons.
- Signed-in Management profile.

## What each section displays

- Trainer Profile displays the trainer’s contact and employment details.
- The upload area shows the supported image formats and maximum file size.
- Assign Classes displays classes that can be associated with the trainer.
- Selected class chips show the trainer’s planned class assignments.

## User interactions

- Upload a trainer photo.
- Enter the trainer’s personal and contact details.
- Select the trainer role.
- Add or remove class assignments.
- Cancel or submit the trainer profile.

## Button and navigation behavior

- **Cancel** returns to the Trainers page without adding the trainer.
- **Add Trainer** submits the trainer profile and selected class assignments.
- Sidebar items open their corresponding management pages.
- **Logout** returns to the management login screen.
