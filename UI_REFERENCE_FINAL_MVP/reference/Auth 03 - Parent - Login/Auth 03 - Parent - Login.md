# Parent - Login

## Screen purpose

- Allows a parent to sign in to the SDS Dashboard.
- Allows the user to switch between Trainer, Management, and Parent sign-in screens.
- Provides access to password recovery.

## Page sections and UI components

- Speech Academy Global logo and tagline.
- **Sign in as** role selector with Trainer, Management, and Parent tabs.
- Welcome message.
- Email and password input fields.
- Password-visibility icon.
- **Remember me** checkbox.
- **Forgot password?** link.
- **Sign in** button.
- Account-access assistance message.

## What each section displays

- The branding area displays the academy identity and tagline.
- The role selector shows **Parent** as the active role.
- The form displays fields for the parent’s email address and password.
- The access message directs users who need an account to contact Management.

## User interactions

- Select an account type.
- Enter an email address and password.
- Show or hide the password.
- Select or clear **Remember me**.
- Open password recovery or submit the sign-in form.

## Button and navigation behavior

- **Trainer** opens the trainer login screen.
- **Management** opens the management login screen.
- **Parent** keeps the parent sign-in screen selected.
- **Forgot password?** opens `Auth 04 - All Users - Forgot Password`.
- **Sign in** submits the entered parent credentials.
