# Trainer - Student Report

## Screen purpose

- Allows a Trainer to view a completed Student Report for one Lesson and its approval status.

## Page sections and UI components

- Trainer Portal sidebar.
- **Student Report** heading and report breadcrumb.
- **Back** control.
- Main report with Overview, Strengths, Areas for Development, and Remarks.
- **Class Video Evidence** section.
- **Report Details** card.
- **Performance Summary** tiles.
- Submission-status message.
- Signed-in trainer profile.

## What each section displays

- The report body displays Alicia Gomez’s Student Report narrative for the selected Lesson.
- Video Evidence displays the associated Student Video recorded during the Lesson and its duration.
- Report Details identifies the Student, Class, Lesson, and Term.
- Performance Summary displays the B.E.S.T. Ratings assigned to speech, tonality, eye contact, and audience awareness.
- The status message indicates that the report was sent to Management for approval.
- Reports sent to Parents are read-only for Trainers; only Management may edit a published report.

## User interactions

- Read the report and assessment summary.
- Play or pause the class recording.
- Return to the reports list.
- Use the sidebar to open another trainer section.

## Button and navigation behavior

- **Back** returns to `Trainer - Reports`.
- The video control plays or pauses the attached recording.
- Sidebar items open their corresponding trainer pages.
- **Logout** returns to the trainer login screen.
