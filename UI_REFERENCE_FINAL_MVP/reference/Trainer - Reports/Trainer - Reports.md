# Trainer - Reports

## Screen purpose

- Allows a Trainer to browse Student Reports they have created for individual Lessons and sent to Management.

## Page sections and UI components

- Trainer Portal sidebar.
- **Reports** heading and description.
- **All Reports** count.
- Sort selector set to **Newest first**.
- Reports table.
- Columns for Student, Class, Lesson, B.E.S.T. Rating, and Status.
- **View** action on each row.
- Signed-in trainer profile.

## What each section displays

- The report count shows the number of available trainer reports.
- Each row displays the Student, Class, Lesson, B.E.S.T. Rating, and report status.
- The table uses the B.E.S.T. Rating categories Beginning, Developing, Mastering, and Mastered.

## User interactions

- Change the report sorting order.
- Select **View** on a report.
- Use the sidebar to open Dashboard, My Classes, Students, or Schedule.

## Button and navigation behavior

- The sort selector reorders the report table.
- **View** opens `Trainer - Student Report` for the selected report.
- Sidebar items open their corresponding trainer pages.
- **Logout** returns to the trainer login screen.
