# Management - Register Student

## Screen purpose

- Allows management to register a new student and assign the student to classes.

## Page sections and UI components

- Management Portal sidebar.
- **Register New Student** heading.
- **Student Profile** section.
- Photo upload area.
- First name, last name, date of birth, gender, and student ID fields.
- Parent name, Parent contact, email, and home address fields.
- **Assign Classes** section with selectable class chips.
- Selected-class count.
- **Cancel** and **Register Student** buttons.
- Signed-in Management profile.

## What each section displays

- Student Profile displays the Student’s basic details and Parent contact information.
- Assign Classes displays the available programmes and levels.
- The selected-class count shows how many classes are currently chosen.

## User interactions

- Upload a student photo.
- Enter the Student and Parent details.
- Select the student’s gender and date of birth.
- Add or remove class assignments.
- Cancel or submit the registration.

## Button and navigation behavior

- **Cancel** returns to the Students page without registering the student.
- **Register Student** submits the student profile and selected class assignments.
- Sidebar items open their corresponding management pages.
- **Logout** returns to the management login screen.
