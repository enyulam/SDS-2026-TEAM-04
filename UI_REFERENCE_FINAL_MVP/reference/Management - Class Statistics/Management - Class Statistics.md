# Management - Class Statistics

## Screen purpose

- Shows Term-level B.E.S.T. Rating statistics and individual Student results for a selected Class.

## Page sections and UI components

- Management Portal sidebar.
- Class breadcrumb and **Class Statistics** heading.
- Summary cards for Students, assessment progress, and assessed count.
- **Skill Averages** chart with rubric criteria and descriptive B.E.S.T. Ratings.
- **Status Distribution** legend and chart.
- **Student Breakdown** table.
- **Class Overview** return link.
- Signed-in Management profile.

## What each section displays

- The summary cards show the Class size and assessment completion.
- Skill Averages compares descriptive B.E.S.T. Ratings across speaking criteria.
- Status Distribution shows how assessed Students are grouped into Beginning, Developing, Mastering, and Mastered.
- Student Breakdown lists each Student’s ID, strongest area, focus area, and B.E.S.T. Rating.

## User interactions

- Review aggregate class results.
- Compare rubric criteria and assessment statuses.
- Review individual Student rows.
- Return to the class overview.

## Button and navigation behavior

- **Class Overview** returns to `Management - Class Overview`.
- A selectable Student row opens that Student’s profile or report.
- Sidebar items open their corresponding management pages.
- **Logout** returns to the management login screen.
