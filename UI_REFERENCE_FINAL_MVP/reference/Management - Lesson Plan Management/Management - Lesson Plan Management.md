# Management - Lesson Plan Management

## Screen purpose

- Allows management to review a class’s term lesson plan, lesson statuses, focus points, and teaching materials.

## Page sections and UI components

- Management Portal sidebar.
- Class breadcrumb and **Lesson Plan Management** heading.
- **Class Overview** return link.
- Term selector.
- Class summary banner with Programme, Level, schedule, room, assigned Trainer, Trainer Assistant (TA), and Student count.
- Status legend for Completed, This week, and Upcoming.
- Weekly lesson cards.
- Focus-point tags.
- Slides and materials list.
- **Upload slides & materials** actions.
- Signed-in Management profile.

## What each section displays

- The class banner displays the six-week unit and its delivery details.
- Each weekly card displays the lesson title, date, location, focus points, status, and available files.
- Lessons without files display “Slides not uploaded yet.”

## User interactions

- Change the selected term.
- Review each weekly lesson and its materials.
- Select an existing material.
- Upload slides or other materials for a lesson.
- Return to the class overview.

## Button and navigation behavior

- **Class Overview** opens `Management - Class Overview`.
- The term selector changes the displayed term plan.
- Selecting a material opens or downloads that item.
- **Upload slides & materials** opens the upload control for the corresponding lesson.
- **Logout** returns to the management login screen.
