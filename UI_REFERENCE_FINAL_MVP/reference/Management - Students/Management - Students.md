# Management - Students

## Screen purpose

- Allows Management to browse all enrolled Students and open their profiles.
- Provides access to creating a Parent account for a Student.

## Page sections and UI components

- Management Portal sidebar.
- **Students** heading and enrolment description.
- **All Students** count.
- Level filter.
- Student table with name, Student ID, Class, Parent, and current B.E.S.T. Rating.
- **View more** actions.
- **Add Parent** action.
- Signed-in Management profile.

## What each section displays

- The page summary displays the total number of enrolled students.
- Each row identifies a Student, their Class or Classes, Parent, and current B.E.S.T. Rating.
- B.E.S.T. Rating badges use Beginning, Developing, Mastering, and Mastered.

## User interactions

- Filter Students by Level.
- Select **View more** for a student.
- Select **Add Parent** to begin parent-account creation.
- Use the sidebar to open another management section.

## Button and navigation behavior

- The Level filter changes the visible Student rows.
- **View more** opens `Management - Student Profile` for the selected Student.
- **Add Parent** opens `Management - Create Parents Account`.
- **Logout** returns to the management login screen.
