# Management - Schedule

## Screen purpose

- Allows Management to view all academy Classes and Lessons on a monthly calendar.
- Shows details for the selected schedule date.

## Page sections and UI components

- Management Portal sidebar.
- **Schedule** heading and description.
- Month selector.
- Calendar grid with class entries.
- **Schedule Details** side panel.
- Selected-date heading.
- Lesson cards with date, time, room, assigned Trainer, and Trainer Assistant (TA).
- Close icon for the details panel.
- Signed-in Management profile.

## What each section displays

- The calendar displays scheduled class names and times on their dates.
- The details panel displays all Lessons for the selected day.
- Each detail card identifies the class and its staff assignment.

## User interactions

- Change the displayed month.
- Select a date or calendar event.
- Review the selected day’s Lesson details.
- Close the details panel.
- Use the sidebar to open another management section.

## Button and navigation behavior

- The month selector changes the calendar period.
- Selecting a calendar item opens its information in Schedule Details.
- The **X** closes the Schedule Details panel.
- **Logout** returns to the management login screen.
