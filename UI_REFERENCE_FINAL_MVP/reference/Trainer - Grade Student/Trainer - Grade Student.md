# Trainer - Grade Student

## Screen purpose

- Allows a trainer to assess one student against the speaking rubric and record observation notes.

## Page sections and UI components

- Trainer Portal sidebar.
- **Grade Student** heading and review status label.
- **Back to Student Roster** control.
- Student list with assessment statuses.
- Selected-student summary.
- **Assessment Rubric** section.
- Four B.E.S.T. Rating choices for each speaking skill: Beginning, Developing, Mastering, and Mastered.
- **Observation Notes** text area.
- **Save & Generate** action.
- Signed-in trainer profile.

## What each section displays

- The student list displays students and their current assessment state.
- The selected-student summary identifies Alicia Gomez, her level, student ID, and programme.
- Assessment Rubric displays the speaking skills and the currently selected B.E.S.T. Rating for each skill.
- Observation Notes provides space for the trainer’s written observations.

## User interactions

- Select a student from the list.
- Choose one B.E.S.T. Rating for each rubric criterion.
- Enter observation notes.
- Save the assessment and continue to report generation.
- Return to the student roster.

## Button and navigation behavior

- **Back to Student Roster** opens `Trainer - Student Roster`.
- Selecting a student loads that student’s assessment.
- Selecting a B.E.S.T. Rating updates that criterion’s choice.
- **Save & Generate** saves the assessment and opens `Trainer - AI Report Generation`.
- **Logout** returns to the trainer login screen.
