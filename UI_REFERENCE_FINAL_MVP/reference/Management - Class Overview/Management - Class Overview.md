# Management - Class Overview

## Screen purpose

- Gives Management a summary of one Class, its assigned Trainer, Trainer Assistant (TA), Students, Lessons, B.E.S.T. Ratings, and report completion.

## Page sections and UI components

- Management Portal sidebar.
- **Class Overview** heading.
- Class summary card with Programme, Level, schedule, room, Student count, assigned Trainer, and Trainer Assistant (TA).
- Rubric focus-area list.
- Weekly lesson timeline with lesson names, dates, statuses, and report counts.
- **Manage lesson plans** link.
- **View Overall Class Statistics** button.
- Signed-in Management profile.

## What each section displays

- The Class card identifies the Junior Public Speaking Class, its schedule, room, Student count, assigned Trainer, and Trainer Assistant (TA).
- The focus-area list displays assessed speaking criteria such as audience awareness, body language, and vocal projection.
- The weekly timeline displays completed and upcoming lessons and the number of reports sent for each lesson.

## User interactions

- Review class information and the lesson timeline.
- Open lesson-plan management.
- Open overall class statistics.
- Use the sidebar to move to another management section.

## Button and navigation behavior

- **Manage lesson plans** opens `Management - Lesson Plan Management` for this class.
- **View Overall Class Statistics** opens `Management - Class Statistics`.
- A lesson item opens its lesson-level details or statistics when selectable.
- **Logout** returns to the management login screen.
