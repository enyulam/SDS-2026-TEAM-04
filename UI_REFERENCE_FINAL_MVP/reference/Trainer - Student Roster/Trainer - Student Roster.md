# Trainer - Student Roster

## Screen purpose

- Supports a Trainer during an active Lesson by showing the Class roster, attendance, Lesson information, and each Student’s assessment status.

## Page sections and UI components

- Trainer Portal sidebar.
- **Student Roster** heading and active-Lesson status label.
- **Back to Schedule** control.
- Active-Lesson summary with Class, room, assigned Trainer, Trainer Assistant (TA), and present-Student count.
- Lesson summary with focus-point tags and material.
- **View lesson plan** link.
- Filter and Sort controls.
- Student cards with attendance, observation, and report status.
- Signed-in trainer profile.

## What each section displays

- The summary identifies the Junior Public Speaking Class, Studio 2, assigned Trainer, Trainer Assistant (TA), and number of Students present.
- The lesson summary displays Lesson 3, Voice & Projection, its focus areas, and the lesson material.
- Each student card displays initials, name, attendance, a short observation, and a status such as Not started, In progress, Pending Approval, or Approved.

## User interactions

- Filter or sort the roster.
- Select a student card to assess or review that student.
- Open the lesson plan.
- Return to the schedule.

## Button and navigation behavior

- **Back to Schedule** opens `Trainer - Schedule`.
- **View lesson plan** opens `Trainer - Lesson Plan`.
- Filter and Sort change the order or subset of student cards.
- Selecting a student who is not yet completed opens `Trainer - Grade Student`.
- Selecting a student with an existing report opens the relevant report view.
- **Logout** returns to the trainer login screen.
