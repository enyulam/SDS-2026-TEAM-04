# Management - Add Class

## Screen purpose

- Allows Management to create a Class and define its Programme, Level, schedule, assigned Trainer, Trainer Assistant (TA), Term, and capacity.

## Page sections and UI components

- Management Portal sidebar.
- **Add Class** heading and `Classes / Add Class` breadcrumb.
- **Class Details** section.
- Class name, Programme, Level, room, and class code fields.
- **Schedule** section with day selectors, start time, end time, and term fields.
- **Assigned Trainer** and Trainer Assistant (TA) selectors.
- Capacity field.
- **Cancel** and **Save Class** buttons.
- Signed-in Management profile.

## What each section displays

- Class Details displays the Class identity, Programme, and Level.
- Schedule displays the selected Lesson days and times.
- Assigned Trainer displays the Trainer selected to lead the Class, together with its Trainer Assistant (TA).
- Capacity displays the maximum number of Students for the Class.

## User interactions

- Enter or edit class information.
- Select the Programme, Level, Lesson days, Term, assigned Trainer, and Trainer Assistant (TA).
- Set the start time, end time, room, class code, and capacity.
- Cancel or save the new class.

## Button and navigation behavior

- **Cancel** returns to the Classes page without creating the class.
- **Save Class** submits the completed class form.
- Sidebar items open their corresponding management pages.
- **Logout** returns to the management login screen.
