# Management - Dashboard

## Screen purpose

- Gives Management an overview of Student assessment activity, Student Reports awaiting approval, approved reports, and academy events.

## Page sections and UI components

- Management Portal sidebar.
- **Dashboard** heading and overview text.
- Summary cards for total students, assessed students, pending approval, and approved reports.
- Reports-waiting-for-approval list with Student, summary, B.E.S.T. Rating, and **Review** action.
- Monthly calendar.
- **Today’s Events** list.
- **View all** links.
- Notification icon and signed-in Management profile.

## What each section displays

- Summary cards display academy-wide total number of students, number of reports assessed, number of pending approval reports, and number of approved reports.
- The approval list displays recent Student summaries and their current B.E.S.T. Ratings.
- The calendar highlights dates containing activity.
- Today’s Events shows event names, dates, times, and locations.

## User interactions

- Select **Review** for a pending report.
- Select **View all** to open the full related list.
- Move between months using the calendar arrows.
- Select an event or highlighted calendar date.
- Use the sidebar to open another management section.

## Button and navigation behavior

- **Review** opens the selected report for management review.
- The report **View all** link opens `Management - Reports`.
- The event **View all** link opens the full schedule.
- Calendar arrows move to the previous or next month.
- **Logout** returns to the management login screen.
