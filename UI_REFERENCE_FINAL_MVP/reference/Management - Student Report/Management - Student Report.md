# Management - Student Report

## Screen purpose

- Allows Management to review a Trainer-submitted Student Report for one Lesson before approving it and sending it to the Parent.

## Page sections and UI components

- Management Portal sidebar.
- **Student Report** heading and **Back** control.
- Main report card with Overview, Strengths, Areas to Grow, and Remarks.
- **Class Video Evidence** section containing the Student Video.
- **Report Details** card.
- **Performance Summary** tiles.
- Approval panel with optional remarks field.
- **Confirm & Approve** and **Save as draft** actions.
- Signed-in Management profile.

## What each section displays

- The main report displays the parent-facing narrative for Alicia Gomez.
- Video Evidence displays the Student Video recorded during the Lesson.
- Report Details identifies the Student, Class, Lesson, and Term.
- Performance Summary displays B.E.S.T. Ratings for speech, tonality, eye contact, and audience awareness.
- The approval panel explains that approval sends the Student Report to the Parent.

## User interactions

- Read the report and performance summary.
- Review the attached class video.
- Add an optional management remark.
- Save the review as a draft or confirm approval.
- Return to the previous report list.

## Button and navigation behavior

- **Back** returns to the previous management report page.
- The video control plays or pauses the attached recording.
- **Save as draft** preserves the current review without approving the report.
- **Confirm & Approve** approves the displayed Student Report and sends it to the Parent.
- If a report has already been sent to a Parent, only Management may edit the published report.
- **Logout** returns to the management login screen.
