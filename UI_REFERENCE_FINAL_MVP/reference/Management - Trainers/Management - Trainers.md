# Management - Trainers

## Screen purpose

- Allows Management to view Trainers and Trainer Assistants (TAs), activity totals, and current employment status.
- Provides access to editing individual trainer profiles.

## Page sections and UI components

- Management Portal sidebar.
- **Trainers** heading and staff-management description.
- **All Trainers** summary count.
- Trainer table with initials, name, activity total, status, and **Edit** action.
- Signed-in Management profile.

## What each section displays

- The summary shows the total number of trainers.
- Each row displays a trainer’s name, activity figure, and status such as Active or On leave.
- The Edit action is available on each trainer row.

## User interactions

- Browse the trainer list.
- Select **Edit** for a trainer.
- Use the sidebar to open another management section.

## Button and navigation behavior

- **Edit** opens the selected trainer’s editable profile.
- Sidebar items open their corresponding management pages.
- **Logout** returns to the management login screen.
