# Management - Term Report

## Screen purpose

- Allows Management to review and approve a Student’s Term Report before sending it to the Parent.

## Page sections and UI components

- Management Portal sidebar.
- **Term Report** heading and **Back** control.
- Main report content with Overview, Strengths, and Areas to Grow.
- Growth Trend section.
- **Report Details** card.
- **Performance Summary** tiles.
- Approval panel with optional remarks field.
- **Confirm & Approve** and **Save as draft** actions.
- Signed-in Management profile.

## What each section displays

- The report content displays Alicia Gomez’s cumulative three-month Term summary and development notes.
- Growth Trend displays the Student’s progress across the Term, based on the Lesson assessments completed during that Term.
- Report Details displays the Student, Class, and Term.
- Performance Summary displays cumulative B.E.S.T. Ratings for speech, tonality, eye contact, and audience awareness.
- The approval panel indicates that approval sends the Term Report to the Parent.

## User interactions

- Read the term report and performance information.
- Review the growth trend.
- Enter an optional management remark.
- Save the review as a draft or approve the report.
- Return to the previous page.

## Button and navigation behavior

- **Back** returns to the previous management page.
- **Save as draft** preserves the current review without approval.
- **Confirm & Approve** approves the Term Report and sends it to the Parent.
- If a report has already been sent to a Parent, only Management may edit the published report.
- **Logout** returns to the management login screen.
