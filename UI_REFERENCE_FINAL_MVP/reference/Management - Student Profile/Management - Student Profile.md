# Management - Student Profile

## Screen purpose

- Gives Management a complete view of a Student’s progress, B.E.S.T. Ratings, reports, Class enrolments, and profile information.

## Page sections and UI components

- Management Portal sidebar.
- **Student Profile** heading.
- Term selector.
- Student summary card with name, standing, Class, Student ID, and Parent.
- **Edit** and **Generate Term Report** actions.
- Growth Trend chart.
- Skill Breakdown chart.
- **Strengths & Focus Areas** tags.
- **Classes Enrolled** list.
- **Profile Details** section.
- Reports table.
- Signed-in Management profile.

## What each section displays

- The Student summary identifies Alicia Gomez and her current Class and standing.
- Growth Trend displays changes in performance over time.
- Skill Breakdown compares individual speaking skills.
- Strengths & Focus Areas separates strong criteria from areas needing attention.
- Classes Enrolled lists the Student’s Programmes, Levels, schedules, assigned Trainers, and Trainer Assistants (TAs).
- Profile Details displays birth date, Parent, contact, enrolment date, and status.
- Reports lists earlier Student Reports with dates, Lesson titles, and B.E.S.T. Ratings.

## User interactions

- Change the displayed term.
- Edit the student profile.
- Start generating a term report.
- Select an enrolled class or previous report.
- Use the sidebar to open another management section.

## Button and navigation behavior

- **Edit** opens `Management - Edit Student`.
- **Generate Term Report** opens the term-report review screen for the student.
- Selecting a report opens its detailed report page.
- The term selector refreshes the progress information for the selected term.
- **Logout** returns to the management login screen.
