# Management - Edit Student

## Screen purpose

- Allows Management to update a Student’s profile, Parent details, and Class enrolments.
- Provides a separate action to withdraw the student.

## Page sections and UI components

- Management Portal sidebar.
- **Edit Student** heading and student breadcrumb.
- **Student Profile** form.
- Photo and **Change photo** control.
- First name, last name, date of birth, gender, and student ID fields.
- Parent name, Parent contact, email, and home address fields.
- **Classes** section with enrolment chips.
- **Withdraw student** warning area and action.
- **Cancel** and **Save changes** buttons.
- Signed-in Management profile.

## What each section displays

- Student Profile displays Alicia Gomez’s current personal and Parent information.
- Classes displays the programmes in which the student is enrolled.
- The withdrawal area explains that withdrawing removes the student from active classes and archives the record.

## User interactions

- Change the student photo.
- Edit Student and Parent information.
- Add or remove class enrolments.
- Start the withdrawal action.
- Cancel or save profile changes.

## Button and navigation behavior

- **Change photo** opens the photo-selection control.
- **Withdraw student** starts the student-withdrawal action.
- **Cancel** returns to the student profile without applying edits.
- **Save changes** submits the edited student information.
- **Logout** returns to the management login screen.
