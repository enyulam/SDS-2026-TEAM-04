# Auth 04 - All Users - Forgot Password

## Screen purpose

- Allows a user to request a password-reset link using their account email address.
- Provides a way to return to sign in.

## Page sections and UI components

- **Reset your password** heading.
- Instruction text explaining that a reset link will be emailed.
- Email input field.
- Pink primary action button.
- **Back to sign in** link.

## What each section displays

- The instruction area tells the user to enter the email associated with their account.
- The form displays one email field and the reset action.
- The bottom link provides a route back to authentication.

## User interactions

- Enter an email address.
- Select the primary button to request the reset link.
- Select **Back to sign in** to leave password recovery.

## Button and navigation behavior

- The primary button submits the entered email address for password recovery.
- **Back to sign in** returns to the relevant sign-in screen.
