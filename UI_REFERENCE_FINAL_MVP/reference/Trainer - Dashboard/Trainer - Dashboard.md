# Trainer - Dashboard

## Screen purpose

- Gives a trainer an overview of assigned classes, students, pending reviews, recent reports, and today’s schedule.

## Page sections and UI components

- Trainer Portal sidebar.
- Personal greeting.
- Summary cards for My Classes, Total Students, and Pending Reviews.
- **My Classes** list with **View all** link.
- **My Recent Report** list with **View all** link.
- Monthly calendar with navigation arrows.
- **Today’s Schedule** list.
- **Start Class** action for the current Lesson.
- Notification icon and signed-in trainer profile.

## What each section displays

- Summary cards display the Trainer’s Class, Student, and pending-review totals.
- My Classes displays Class names, Student counts, and rooms.
- My Recent Report displays Students, brief assessment notes, B.E.S.T. Ratings, and submission times.
- The calendar highlights dates with scheduled activity.
- Today’s Schedule displays Lesson times, Class names, rooms, and a staff meeting.

## User interactions

- Select a class or recent report.
- Open the full class or report list.
- Move between calendar months.
- Select a highlighted date.
- Start the current Lesson for the selected Class.
- Use the sidebar to open another trainer section.

## Button and navigation behavior

- The My Classes **View all** link opens `Trainer -  My Classes`.
- The recent reports **View all** link opens `Trainer - Reports`.
- Calendar arrows move to the previous or next month.
- **Start Class** opens the active Lesson and Student Roster for its Class.
- **Logout** returns to the trainer login screen.
