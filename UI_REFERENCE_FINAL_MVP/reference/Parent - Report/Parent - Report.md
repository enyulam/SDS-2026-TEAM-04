# Auth 03 - Parent - Reports

## Screen purpose

- Allows a Parent to browse approved reports received for the selected Student.
- Provides a summary list of report topics, Classes, Lessons, Trainers, dates, and B.E.S.T. Ratings.

## Page sections and UI components

- Parent Portal sidebar with Overview, Calendar, Reports, and Logout.
- **Reports** page heading and Student-specific supporting text.
- **All Reports** list.
- Report rows with an icon, report title, B.E.S.T. Rating, Class, Lesson, Trainer, and received date.
- Selected-Student panel showing Alicia Gomez and Junior Level.
- Signed-in Parent profile showing Maria Gomez.

## What each section displays

- The sidebar highlights **Reports** as the active page.
- The report list displays class reports such as Expressive Delivery, Body Language & Posture, Intro to Persuasion, and Voice & Projection.
- Each row shows the report’s B.E.S.T. Rating and identifying Lesson information.
- The account area identifies the Parent and the Student whose reports are being viewed.

## User interactions

- Select a report from the list.
- Use the sidebar to open Overview, Calendar, or Reports.
- Select **Logout** to leave the Parent Portal.

## Button and navigation behavior

- **Overview** opens the parent dashboard.
- **Calendar** opens `Parent - Calendar`.
- **Reports** keeps the current report-list page selected.
- Selecting a report opens its detailed Student Report for the selected Lesson.
- **Logout** signs the parent out and returns to the parent login screen.
