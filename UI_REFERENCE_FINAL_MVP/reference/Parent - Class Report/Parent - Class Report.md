# Parent - Class Report

## Screen purpose

- Allows a Parent to read an approved Student Report for one Lesson and review the attached Student Video.

## Page sections and UI components

- Parent Portal sidebar.
- **Class Report** heading with subject and date.
- Main report card with Overview, Strengths, Areas for Development, and Remarks.
- **Report Details** card.
- **Performance Summary** tiles.
- **Watch Together** video section with duration and play control.
- Student selector and signed-in Parent profile.

## What each section displays

- The report card displays Alicia Gomez’s progress narrative, strengths, development areas, and trainer remarks.
- Report Details identifies the Student, Class, Lesson, and Term.
- Performance Summary displays B.E.S.T. Ratings for speech, tonality, eye contact, and audience awareness.
- Watch Together displays the Student Video recorded during the Lesson and a message encouraging the family to review the speech at home.

## User interactions

- Read the approved report.
- Play or pause the attached class video.
- Change the Student being viewed.
- Use the sidebar to open Overview, Calendar, or Reports.

## Button and navigation behavior

- The video play control starts playback of the attached recording.
- The Student selector changes the Student whose information is displayed.
- The published report is read-only for the Parent; only Management may edit it.
- **Overview** opens `Parent - Dashboard`.
- **Calendar** opens `Parent - Calendar`.
- **Reports** returns to the parent’s report list.
- **Logout** returns to the parent login screen.
