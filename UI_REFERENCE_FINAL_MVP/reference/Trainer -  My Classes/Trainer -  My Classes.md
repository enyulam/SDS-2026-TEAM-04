# Trainer -  My Classes

## Screen purpose

- Allows a trainer to view the classes assigned to them for the selected term.

## Page sections and UI components

- Trainer Portal sidebar.
- **My Classes** heading.
- Term selector.
- Class cards for Public Speaking and Speech and Drama programmes.
- Programme and level labels.
- Student counts.
- Schedule, room, and next-Lesson information.
- Signed-in trainer profile.

## What each section displays

- Each Class card displays the Programme, Level, number of Students, regular schedule, room, assigned Trainer and Trainer Assistant (TA), and next Lesson.
- The term selector displays the period used to filter the class list.

## User interactions

- Change the selected term.
- Select a class card.
- Use the sidebar to open Dashboard, Students, Reports, or Schedule.

## Button and navigation behavior

- The term selector updates the class list for the selected term.
- Selecting a class card opens its lesson plan or class details.
- **Dashboard** opens `Trainer - Dashboard`.
- **Students**, **Reports**, and **Schedule** open their corresponding trainer pages.
- **Logout** returns to the trainer login screen.
