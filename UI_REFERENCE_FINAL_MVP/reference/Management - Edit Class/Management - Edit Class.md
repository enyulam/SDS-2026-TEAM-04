# Management - Edit Class

## Screen purpose

- Allows Management to update an existing Class’s details, schedule, assigned Trainer, Trainer Assistant (TA), Term, and capacity.

## Page sections and UI components

- Management Portal sidebar.
- **Edit Class** heading and class breadcrumb.
- **Class Details** section.
- Class name, programme, level, room, and class code fields.
- **Schedule** section with day selectors and time fields.
- Assigned Trainer, Trainer Assistant (TA), Term, and capacity controls.
- **Cancel** and **Save Class** buttons.
- Signed-in Management profile.

## What each section displays

- The form is pre-filled with the current class information.
- The schedule shows the Class’s selected Lesson days and times.
- The staff fields identify the Trainer and Trainer Assistant (TA) assigned to the Class.

## User interactions

- Edit the class information.
- Change the selected Lesson days, times, Term, Trainer, Trainer Assistant (TA), or capacity.
- Cancel or save the changes.

## Button and navigation behavior

- **Cancel** returns to the class area without applying changes.
- **Save Class** submits the edited class information.
- Sidebar items open their corresponding management pages.
- **Logout** returns to the management login screen.
