# Parent - Dashboard

## Screen purpose

- Gives a Parent an overview of the selected Student’s current B.E.S.T. Ratings, profile details, calendar, and upcoming events.

## Page sections and UI components

- Parent Portal sidebar.
- **Alicia’s Progress** heading and summary text.
- **This Term’s Skills** list with performance indicators.
- **Profile Details** section.
- Parent and Student selector panel.
- Monthly calendar.
- **Upcoming for Alicia** event list.

## What each section displays

- This Term’s Skills displays current B.E.S.T. Ratings for body, eye contact, emotion, speech, tonality, vocal projection, emotional expression, sentence flow, and audience awareness.
- Profile Details displays date of birth, Parent, contact, Class, assigned Trainer, Trainer Assistant (TA), and enrolment date.
- The account panel identifies Maria Gomez and shows the Students available to view.
- The calendar highlights relevant dates.
- Upcoming for Alicia displays future activities with dates, times, and locations.

## User interactions

- Change the Student being viewed.
- Select a highlighted calendar date.
- Select an upcoming event.
- Use the sidebar to open Calendar or Reports.

## Button and navigation behavior

- Selecting a Student refreshes the dashboard for that Student.
- Selecting a calendar date displays the related activity when available.
- **Calendar** opens `Parent - Calendar`.
- **Reports** opens the parent report list.
- **Logout** returns to the parent login screen.
